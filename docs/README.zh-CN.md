**当前版本：V2.3（完整版本 2.3.20260925）。** V2.2（2.2.20260924）仍为已发布基线；本版本增加源表图标、批量目标列表、跟踪视场曲线、排序窗口和计划预览排序。

## 1. 简介与目标

Skyward 是面向天文台和望远镜的观测辅助平台。当前 LACT/LHAASO 适配使用可解释的几何模型，分析目标位置、约束和候选观测窗口。正式版本为 **V2.2（完整版本 2.2.20260924）**，不会发送设备指令，也不替代调度、值班人员或安全联锁。

## 2. 当前功能

- 首页和结果页全天图支持地平、FK5 J2000、银道坐标；默认经度 60°、纬度 30° 稀疏网格。每个非 Gaia 源表都可选择星星、菱形、三角形、方形、圆形或十字图标，选择保存在当前浏览器并由首页/结果页地图共享；Gaia 始终使用固定十字符号，extension 始终使用青色空心圆。
- “勾选草稿—确认加载”的普通源表选择：各源表记录数由源表接口动态提供，并支持临时 CSV。用户上传 CSV 文件需包含表头和 `name,ra,dec`（坐标为 J2000 度），可参考 name、RA、Dec 示例；还可选填扩展与不确定度字段。完整字段、限制和备选目录样例见数据说明页“CSV 上传格式与示例”。
- 所有结果局部图固定以目标为中心显示直径 10°；LACT 直径 8.3° 硬 FoV 是独立蓝色虚线框。
- Gaia DR3 只在结果页局部图通过“加载 Gaia DR3”按钮查询；不出现在任何全天图选择器/图层，也不成为窗口目标。结果页全天图切换到“观测窗口”模式后，可点击“添加所有跟踪视场内源曲线”；目标源和曲线源的完整窗口会按起始时间在几何量与完整源窗口顶部排序：首页还支持批量目标 CSV，必填 `name,ra,dec,ext`，5 个观测约束列可选，缺失项继承规划器设置；有效窗口会自动加入当前浏览器观测计划，局部视场图和观测窗口图默认保存，随后可在预览中修改。预览支持按添加时间、观测窗口总时长和窗口起始时间排序。用户可设置目标周围 0.1–5° 半径、最暗 G 星等（5–22）和最大源数（1–500）；默认 1°、G≤10、10 颗；若符合条件的源超过上限，按与目标的角距离由近到远选择最近的 N 颗。
- Gaia 候选星使用红/绿色十字符号；普通目录源仍是红/黄/绿星形。精确参数缓存优先复用；比默认更广、更暗或更多的查询使用异步 TAP。返回结果在原查询圆锥内按与目标的角距离由近到远排序并截取最近 N 颗，不代表完整星表。
- 单次窗口最长 30 天；逐秒候选扫描按有界块运行，跨块窗口合并，展示序列有界下采样。
- 源详情、中英文、亮/暗/自动主题、北京/UTC、显示缩放，以及浏览器标签页内持续累积的观测计划。完整源窗口逐行显示并默认全部勾选，但“预览”“加入”和“下载”只保留一组；一次加入会把全部勾选窗口保存为同一条目标计划。每个窗口分别筛选 0–3 个备选源：先按窗口重叠、时间间隔、时长差和稳定源键排序粗筛，再对入围源逐一精确验证；用户也可上传专用 CSV 备选源目录，上传后只从该目录挑选，否则使用当前已加载普通源表。预览可逐窗口修改时段。导出 ZIP 中的 `skyward-observing-plan.xlsx` 为每个所选窗口写一条黄色目标行，并在其后写绿色备选源行；表头为纯黑色。排序指标、阶段、警告和窗口编号均保留；勾选保存图像时，每条目标计划的局部视场图和观测窗口图以独立 SVG 文件写入 `plots/`；观测窗口图包含多条 Zenith-Time 曲线图例，局部视场图使用亮背景、目标编号 1 和源名图例。

## 3. 科学与安全边界

默认 LACT 站点为东经 100.0266666667°、北纬 29.3575°、海拔 4410 m，理想圆形 FoV 直径 8.3°。当前版本尚未接入可信的望远镜实时指向，因此任何地图状态和源可观测性判定都不把“是否位于当前 FoV”作为约束；蓝色 FoV 圆仅用于目标中心周围的几何展示。

窗口计算可使用太阳高度、月亮角距、目标天顶角、名义 footprint 和最短持续时间。若源的 extension 未知，则按零半径点源回退计算，并保留明确警告；这不代表真实扩展源范围已经验证。不评估天气、云、气溶胶、设备健康、机械限位、跟踪误差、真实响应/灵敏度、优先级或正式联合观测批准。绿色状态和候选窗口不是正式授权；逐秒扫描也不保证发现所有亚秒窗口。

默认目录为公开论文 *The First LHAASO Catalog of Gamma-Ray Sources*（DOI `10.3847/1538-4355/acfd29`）Table 2 的 1LHAASO 规范化快照，共 90 个命名源和 180 个 WCDA/KM2A 组件。双组件源按论文规则采用有坐标组件中 TS 较高者的位置；所有组件的坐标、95% 统计位置误差、r39、TS、N0、光子谱指数、TS100、关联项、缺失值和上限均保存在来源字段中。r39 是二维高斯模型的 39% containment radius；测得扩展的误差是 1σ 统计误差，点源条目给出 95% 置信上限。它不等于经过验证的物理硬边界，因此 1LHAASO 的 `planning_radius_deg` 保持未知，几何计算使用带警告的点源回退。Table 2 的关联项是论文按位置搜索得到的初步已知 TeV 对应体，不是 Skyward 核验的源身份。N0 对 WCDA/KM2A 的单位分别为 `10^-13`/`10^-16 cm^-2 s^-1 TeV^-1`，参考能量为 3/50 TeV；机器表中未探测分量的零值按论文语义保存为上限，而不是科学零值。尚未公开发布的 2LHAASO 源表不随 V2.2 提供，也不会作为内置目录或保留名称由页面/API 提供；临时用户上传仍是用户自行负责的数据，但不能使用 2LHAASO 保留名。文档仅保留这一发布边界说明。

TeVCat 公开快照截止 2026-09-19。223 条上游“Extended: No”记录按零半径已知点源处理；140 条“Extended: Yes”记录没有经核验的硬边界角半径，保留未知 footprint。跨表近邻只表示候选关系，不代表同一天体，也不复制物理参数。

Gaia 备注可包含源 ID、ICRS/J2000 坐标、G/BP/RP 星等、视差、简单逆视差距离、自行、RUWE、可见周期和来源。简单距离没有先验或不确定度修正；J2016.0 方向转换到 FK5 J2000 时未传播自行。

## 4. 使用流程

1. 在首页全天图打开“选择源表”，勾选普通目录并点击“确认加载”。取消、Esc 或点击弹层外部不会应用草稿；允许全部取消。
2. 选择目录目标，或输入临时目标名称、RA、Dec 和半径。
3. 设置起止时刻（最长 30 天）以及太阳、月亮、天顶角和最短窗口约束，提交计算。
4. 在结果页检查目标状态、全天图、直径 10° 局部图、曲线和窗口。两张图共享“实时”“观测窗口”和“指定时间”状态、普通源颜色及观测窗口内跟踪视场源的紫色轮廓；指定时间支持一个时间点或不超过 24 小时的时间段。切换普通显示源表不改变已计算目标；结果页目标源详情不提供“填入观测规划”，其他普通源仍可从详情填入并作为新目标重新计算。
- 5. 需要局部候选星时设置查询半径（0.1–5°）、最暗 G 星等和最大源数量，再点击“加载 Gaia DR3”。默认使用 1°、G≤10、10 颗；若符合条件的源超过上限，按与目标角距离由近到远选择最近的 N 颗；普通源保持。Gaia 按两张图共享的实时/观测窗口/指定时间状态计算可观测性，并以绿色或红色加粗十字符号显示；状态区给出可观测/不可观测数量，并区分查询中、缓存、成功零行、截断和失败。取消只移除 Gaia。
6. 在结果页的完整源窗口区域，可逐行保留或取消窗口，再使用标题右侧唯一一组计划操作。结果页切换到“观测窗口”模式后，可点击“添加所有跟踪视场内源曲线”；目标源和曲线源的完整窗口会按起始时间在几何量与完整源窗口顶部排序：首页还支持批量目标 CSV，必填 `name,ra,dec,ext`，5 个观测约束列可选，缺失项继承规划器设置；有效窗口会自动加入当前浏览器观测计划，局部视场图和观测窗口图默认保存，随后可在预览中修改。预览支持按添加时间、观测窗口总时长和窗口起始时间排序。用户上传 CSV 源表和专用备选源目录都必须是带表头的 UTF-8 CSV：至少包含 `name,ra,dec`，坐标为 J2000 度；可选 `ext,ext_err,p_err(95%),l,b`。例如：

~~~csv
name,ra,dec,ext,ext_err,p_err(95%)
Crab,83.6331,22.0145,0.10,0.02,0.01
Example source,120.5,-30.2,,,
~~~

可下载对应的[用户源表 CSV 示例](../app/static/examples/user-source-catalogue.csv)。备选源目录使用同一格式，例如 `name,ra,dec,ext`；在结果页上传后，它只作为当前观测计划的备选源池，不替换目标或已加载源表。另可下载[备选源目录 CSV 示例](../app/static/examples/alternative-source-catalogue.csv)。文件限制为最多 1,000 行、512 KiB；名称需唯一且 1–80 个字符；RA/Dec 必须分别满足 0 ≤ RA < 360、−90 ≤ Dec ≤ 90；负的扩展或不确定度会被拒绝。数据说明页也列出字段说明和范例。

结果页离开到“数据说明”或“API”前会在当前浏览器标签页的 sessionStorage 中保存已渲染的结果视图；从这些页面点击“天区与规划”时直接恢复原来的地图、模式、时间、Gaia 图层、缩放和曲线，不重新计算窗口或请求地图。只有直接刷新、缓存不可用或跨标签页访问时才回退到服务器重建结果；这条规则只针对结果页视图，观测计划仍按下述生命周期保留。结果页目标源详情不提供“填入观测规划”，其他普通源仍可从详情中填入规划并替换当前目标；Gaia 候选星只用于局部图显示。局部视场的缩放控件与标题同行显示，状态模式仍与全天图共享。

### 观测计划的存储、隔离与生命周期

观测计划只保存在当前同源网页的浏览器 `sessionStorage` 中，不写入 Skyward 服务器数据库。隔离边界是“同源 + 浏览器会话 + 标签页”：不同电脑、不同浏览器、不同浏览器配置文件和彼此独立的隐私会话互不共享计划。当前版本没有登录、账号、租户或服务器端权限隔离，因此这不是账号级安全隔离；多人共用一台电脑时，应使用各自的浏览器配置文件或独立会话，并在结束前使用页面中的“清空当前观测计划”。

同一标签页内，观测计划按以下规则处理：

| 操作 | 计划状态 |
| --- | --- |
| 刷新标签页 | 保留 |
| 从计算窗口进入“数据说明”或“API”后返回 | 保留 |
| 浏览器前进、后退 | 保留 |
| 点击“清空当前观测计划” | 清空 |
| 关闭标签页后重新打开 | 按新会话处理，清空 |
| 关闭整个浏览器后重新打开 | 按新会话处理，清空 |
| 清理网站数据 | 清空 |
| 隐私模式会话结束 | 清空 |

应用存储容器从 `skyward.observation-plan.v2` 升级到 `v3` 时不迁移旧计划。浏览器的“恢复上次会话”或“重新打开已关闭标签页”可能恢复 `sessionStorage`，这是浏览器实现相关的例外；如果浏览器恢复了旧标签页，不能把它误认为新的空白会话。

## 5. 本机快速安装

~~~bash
cd /path/to/skyward
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
mkdir -p .runtime/matplotlib .runtime/cache
export MPLCONFIGDIR="$PWD/.runtime/matplotlib"
export SKYWARD_CACHE_DIR="$PWD/.runtime/cache"
.venv/bin/python -m pytest -p no:cacheprovider -q
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
~~~

在服务器本机访问 http://127.0.0.1:8000/。LAN、systemd、离线 wheelhouse、升级和回滚见[部署手册](DEPLOYMENT.zh-CN.md)。服务没有账号和授权隔离，禁止直接暴露公网。

## 6. 常见问题

- 升级后仍是旧界面：重启实际运行进程，再用 Ctrl+Shift+R 硬刷新。
- Gaia 不显示：它只存在于结果页局部图；点击加载按钮并读取状态区。失败不能解释成零行。
- 本地源正常而 Gaia 失败：检查服务器 DNS、TLS、批准的出站策略和有限网络超时；本地几何不依赖 Gaia。
- HTTP 422：检查时间顺序、30 天上限、参数范围和活动 IERS 覆盖。
- 1000× 是否提高精度：否，只是显示放大。

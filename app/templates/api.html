Window request example

{
  "source_key": "1lhaaso:",
  "catalog_tokens": "1lhaaso",
  "start_time": "2026-12-15T10:00:00Z",
  "end_time": "2026-12-16T10:00:00Z",
  "constraints": {
    "sun_max_altitude_deg": -18,
    "moon_min_separation_deg": 30,
    "target_min_zenith_deg": null,
    "target_max_zenith_deg": 50,
    "minimum_window_seconds": 1800
  }
}

A response with geometry_only=true does not evaluate weather, telemetry, mechanical safety or joint-observation conditions.

The alternatives endpoint evaluates one target window per request. A browser plan containing multiple selected windows sends one bounded request for each window and stores each result with that window.
